# TypeGenius

## Overview

TypeGenius is a full-stack web application designed to help users improve their typing speed and accuracy through interactive typing tests and real-time performance tracking.

## Features

* User-friendly typing test interface
* Real-time words per minute (WPM) calculation
* Accuracy tracking
* Dynamic typing passages
* Responsive design
* Frontend and backend integration

## Technologies Used

### Frontend

* Angular
* TypeScript
* HTML
* CSS

### Backend

* Java
* Hibernate
* JPA
* Spring Boot
* REST APIs

### Database

* MySQL

## Project Structure

TypeGenius

├── Frontend (Angular)

├── Backend (Spring Boot)

└── Database (MySQL)

## How to Run

### Frontend

1. Navigate to the frontend folder.
2. Install dependencies:
   npm install
3. Start the Angular application:
   ng serve
4. Open http://localhost:4200

### Backend

1. Navigate to the backend folder.
2. Configure MySQL database.
3. Run the Spring Boot application.
4. Backend server will start on http://localhost:8080
